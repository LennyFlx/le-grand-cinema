# Fixture des salles

`salles_initiales.json` utilise une convention de 20 places par rangée (A, B,
etc.), numérotées de 1 à 20. Pour les salles de 70 places, la dernière rangée
contient seulement 10 places. Cette disposition est un choix du projet :
l'énoncé précise les capacités, mais ne fournit pas de plan des salles.
